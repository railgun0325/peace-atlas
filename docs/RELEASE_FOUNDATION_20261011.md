## 本批功能

- 自动审核默认复用一小时内成功读取的公开网页，可以强制刷新或关闭跨任务复用。页面内容哈希、提取器版本和时效仍需有效；每个目标的账号归属依据独立校验。复用的是来源捕获，不复用另一个账号的核验结论。
- 报告在付费分析前保存完整输入快照。重试先免费预览，明确选择原输入续跑或使用最新审核状态重新生成；输入在预览后发生变化会拒绝过期提交。旧任务缺失完整快照时不会假装恢复原输入。
- 正常任务状态只返回输入快照摘要，避免每次刷新都传递新增的整份快照；独立报告与内部保存仍保留完整来源。
- 外部 Agent 新增 `job.retry_preview`。自动审核任务的取消与重试需要 `review` 权限；普通研究的 `run` 权限不能代替它。

参数和操作见 [Agent 补充说明](USER_MANUAL_20261010_AGENT.md) 与 [接口契约](AGENT_INTEGRATION.md)。部分实现的实测收益和局限见 [基础改进记录](FOUNDATION_IMPLEMENTATION_20261011.md)，后续方向见 [路线图](ROADMAP.md)。
