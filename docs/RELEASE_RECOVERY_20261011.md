# 报告续跑与跨平台启动修复候选

日期：2026-10-11。产品版本 2.0.0，资产后缀 `foundation-recovery-20261011`，计划发布到私有标签 `v2.0.0-foundation-recovery.20261011`。当前处于修复与验收阶段，尚无本版本已发布安装包。

本批承接 [来源复用与报告恢复版](RELEASE_FOUNDATION_20261011.md)，处理实际运行发现的三个问题：

- 报告在选择最新输入或切换 Harness 模式后，不再沿用不匹配的后续阶段和旧进度；同一输入仅放宽运行上限仍保留有效检查点。
- Mac 主程序与 `CFBundleExecutable` 同步使用 `PEACE ATLAS`，使 Electron 正确识别打包应用并选择包内后端。原 `Electron` 名称造成的宿主 Python／开发入口错误已有真实 Mac 失败日志。
- 复核请求仅对第一层中逐值一致的来源和阅读记录去重，以明确的原片段引用替代第二份副本。原文、元数据、候选笔记、批次边界与已完成检查点保留；不改变模型上下文上限、不接受截断输出、不把不同片段或高层笔记合并。

第三项来自真实 601 条材料任务的失败现场。失败批次包含 204 个原始片段和 125 条候选结论；原请求按保守字节上界只能预留 33,467 token，实际响应因长度结束。对保存输入的离线重放显示，去除重复副本可减少 362,434 个 UTF-8 字节，恢复原有 65,536 token 输出预留，并容许既有长度恢复逻辑继续增加预留。该结果是精确输入字节与容量检查的测量，不是实际账单降幅，也不是模型语义复核已成功。

## 验收状态

进度与 Mac 打包修复的第一轮完整回归为 2,768 后台、198 前端、62 桌面、25 构建，共 3,053 项通过。该轮早于最后的复核请求去重补丁；完整合并版需新的冻结和验收，不能沿用它作为最终包的通过记录。

最终源码清单、完整回归、两平台构建、Windows 隔离原生／Agent／SDK 路径、正式数据升级和真实模型续跑结果将在实际执行后补齐。平台工作流从固定完整源码提交构建，只有该平台原生路径通过后才上传安装包到同一个私有草稿。发布还需核对服务器资产大小及 SHA256。

Windows 与 Mac 的 runner 包和本机包可能因归档时间或 Mac ad-hoc 签名而具有不同 ZIP 哈希；分别提供准确哈希与受测资产收据，并核对同一应用源码清单。Mac 目标是 Apple Silicon macOS 13+；Apple Developer ID 签名与公证未进行。
