## 本轮修复的实际问题

账号类型判定此前与独立身份核验绑定，导致账号已保存自己的明确公开简介，仍不能用于“组织／个人”的发布主体类型分类。本轮允许仅依据该账号自己的保存简介分类，要求准确主页、实际读取记录及简介内逐字摘录完整匹配。结果明确记录公开自述的依据；不授予账号身份核验、组织隶属或个人政治身份。只有名称、旁人介绍或缺少简介时仍保留未知。独立出处核验与人工锁定规则保留。

活动旧审核要求原句出现完整年份与标准都道府县名，许多实际正文中的“本日／昨日”和明确场所因此全部落入证据不足。本轮对同一活动的保存公开正文建立日期、地点及举行描述依据：具备匹配的原生平台正文、原帖编号、DOM 作者和可靠带时区发布日期时，按日本时间解析受控相对日期；明确年份则直接使用原文年份。月份日期不能随意借用年份，未来预告、否定、历史引用、转发和译文不能冒充已举行活动。场所可由受控别名定位；无法明确定位时保留未定位。

活动依据范围记录为 `source_claim_only`：核对的是保存来源所述的举行信息，不能声称独立验证事件事实。日本地图仍只统计所选实际活动日期范围内，已核对、已定位、去重后的活动数量占比；原帖发布地、组织地址和背景地名不进入分母。

标准 DSH 报告已具备版本化逐字摘录凭据，本轮进一步保存并传递纠正政策：累计最多六次，连续两次没有新增有效证据即停止；旧累计消耗不清零。有效进展依据是新增合格读取和核对对，重复读取、改写候选或更换窗口 token 不算进展。自动审核自定义合同保留原独立限制，严格引用及安全诊断要求不降低。
