## 本次修复

- 模型请求出现空响应、无效 JSON、可恢复网络错误或 408/429/500/502/503/504 时，在同一待处理请求上最多尝试三次，退避 0.5/1 秒，并遵守共同截止时间。已经完成的工具操作不重复执行；取消、永久错误、合法 JSON 中的语义错误不会靠盲目重试掩盖。请求次数包含失败尝试，不能等同于成功决策次数或精确账单。
- 保存模型传输诊断代码、HTTP 状态、响应长度和摘要，便于定位长任务失败；诊断不保存原始响应、请求头、密钥或推理内容。超过恢复次数后仍保存断点，允许后续从剩余范围重试。
- 自动审核遇到原文没有完整活动年份、月日或必要描述时，将能够明确识别的证据缺口保存为“证据不足”，并继续处理后续批次。不能用文章发布日期补足活动年份，不能因为缺少证据就判为虚假。
- 关系主张必须获得完整限定语的支持，例如地区、刊物身份和领导者关系。原文只支持其中一部分时，不再确认整条主张，也不删除限定语来让审核通过。
- 需要调查的未知账号，在允许联网的任务中必须实际执行对应账号调查并保存诊断。无关搜索结果不再充当该账号的支持证据。
- 官方或人工登记来源的信任只作用于其准确对应的账号；其他嘉宾、文章提及、自动发现来源或同站不同文章不能借用这份身份依据。
- 原始材料、审核历史、身份核验、账号类型与关系主张仍分别保存。未知类型和证据不足是合法结果，不能为了清零待办而改成“已确认”。

功能入口包括桌面“自动审核与核验”按钮，以及授权 Agent 接口的审核队列、预览、批量执行和后台任务操作。DSH 已执行真实工具循环；自动审核不是直接接收一次模型回答后写入数据库。
