## 实际问题与本轮修复

此前真实任务已完成全部 601 条来源审阅，并保存 140 条 DSH 工具记录。恢复模型可以从长历史中重新输出原句，但结束引用必须与同编号的已读窗口及成功逐字核对对完全一致。上一阅读条件候选实际没有新增工具，完整回复因 `unchecked_quote` 被拒，没有保存正式报告。被拒正文未保留，因此不能猜测是哪条摘录或何种文本差异。

本轮引入明确版本的标准报告内部引用合同 `QUOTE_RECEIPT_WIRE_VERSION=1`。模型可以选择 `{citation_id,receipt_id}`；工作台仅依据当前 gateway 范围内重新核验合格的实际读取与逐字核对记录生成凭据，并无损还原 `{citation_id,quote}`，随后执行原严格 validator。保存 findings 仍保留原句格式。这是内部传输合同扩展，不描述为单纯提示修改。

凭据绑定版本、当前来源快照、引用编号、全文 hash、原句 hash 与实际读取窗口及片段 hash。损坏的读取编号、总字数、返回字数、布尔冒充整数、偏移和 hash 不能生成可用凭据。未知凭据、跨快照、跨编号、错版本或同一对象混用原句与凭据均拒绝；传统原句继续严格核对，不做近似匹配或自动替换。

启动和恢复上下文向模型提供合格引用目录。缺少可用引用时仍需模型实际补读并逐字核对；程序不伪造阅读或工具记录。模型结束候选与实际完成回复使用同一还原过程，原始候选一致性、会话和运行绑定保持。纯工具结果、旧父任务及完整 trace 不重写。

`SYSTEM`、gateway/schema、研究输入指纹公式及自动审核的自定义合同保持。完成检查点复用仍先严格复验，累计纠正次数和模型/工具/传输消耗不清零。引用可追溯不表示事实、组织身份或隶属已核验；成稿仍独立复核来源角色、主体与论证限定。

安全诊断继续只保存固定错误分类及有界的 finding/quote 位置，新增凭据错误与未经核对原句的位置。拒绝日志不保存候选正文、原句或任意引用编号；历史缺少位置时保持未知。
