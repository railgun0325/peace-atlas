# PEACE ATLAS 操作说明书

版本：2026 年 10 月 11 日 · 长任务与估时、DSH 取证、来源复用、报告续跑、外部 Agent 接口及通用 Skill。

本手册介绍如何从公开材料开始，探索账号关系、核对证据、生成报告并保留研究数据。本轮补充范围完成、启动前估时、详细进度、高效证据缓存及外部 Agent 操作；你使用的桌面版本和实际可用能力，以应用显示及“能力与设置”为准。真实 DSH 或 AI 分析是否完成，以任务中心终态和实际保存的报告为准，本手册不预先认定正式桌面已经切换或真实分析已经成功。

首次使用，建议先照第 2 节完成一个小范围研究，再逐步扩大读取范围。离线 HTML 可直接双击打开，使用目录跳转和 Ctrl+F 查找“账号上限”“继续 AI 分析”“备份”等词。

## 1. 页面与整体流程

|主要页面|在这里做什么|结果到哪里看|
|---|---|---|
|情报总览|查看材料概况、主题与地名提及，核对日本活动地图|地图下方的活动记录、资料库|
|研究工作台|新建普通采集或账号关系研究，设置单次任务或连续任务串，恢复未提交草稿|本页已有研究结果、资料库|
|账号关系图|跨研究查看已保存的公开关系，按方向、跳数和结构层级强调，查看账号类型与依据|点击账号或连线后的详情|
|任务中心|看排队、进度、诊断、取消与重试，查看任务串汇总|任务详情、关联研究或生成报告|
|资料库|检索新闻与社媒材料，读保存正文及原始来源，导入、核对活动、清理|资料详情、回收站|
|组织与账号|登记公开账号、编辑资料、人工核验或排除，查看关系记录|账号卡片、账号关系图|
|研究报告|生成证据整理或 AI 分析报告，阅读与下载来源快照|保存报告及其引用|
|能力与设置|查看采集组件和会话状态，配置 AI 连接，备份恢复，打开数据和日志目录|本页状态、任务中心|

通常按这个顺序操作：**检查能力与会话 → 创建研究或采集 → 在任务中心跟踪 → 回到资料与关系逐条核对 → 生成报告 → 下载报告和研究备份。** 活动地图、账号人工核验和资料清理是在核对材料时使用的辅助步骤。

“采集公开材料”主要取得新闻与帖子；“探索账号与关系”还会保存起点、每层发现路径、公开关系及分析。任务串是执行安排，可以用于两种工作。它是一组有限任务的队列，不是每天自动运行的定时计划。

页面上“已连接”只说明本地服务能响应；采集组件就绪、社媒登录已验证、账号主体已核验、AI 配置存在和真实分析成功是不同状态。请分别查看对应结果。

## 2. 第一次指定账号研究：照着做一遍

下面的方案用于先确认流程，账号请换成你确实要研究的公开账号。它不会保证一定取得多少材料，也不会保证最终判断正确。

1. 打开“能力与设置”。如果要读 X 或 Instagram，先完成该平台的“检测并复用已有登录”，确认采集会话已验证；只查新闻时无需社媒登录。
2. 打开“研究工作台”，点击“探索账号与关系”。工作内容选“探索账号与关系”，执行安排选“单次任务”。
3. 在 X 或 Instagram 选择“指定公开账号”，填写用户名，例如自己的研究对象的 `public_handle`，不要填密码、API Key 或登录信息。仅勾选确实要访问的社媒平台。账号起点模式不使用新闻作为初始入口。
4. “其他研究起点”第一次留空。关键词可留空，表示不另加主题限制；如果只查反战活动，可填较具体的研究词。研究问题可写“此账号近期公开活动有哪些可核对来源？与哪些账号存在已观察的关注或提及？”
5. 日期先选“近 7 天”；向下探索层数填 **1**，最多探索账号 **6**，最多记录关系 **30**，最多保存条数 **50**，每页最多滚动 **5**，运行时间 **900 秒**。沿关注账号和沿帖子提及开启，被关注展开先关闭。
6. 首次选“公开证据整理 · 不调用 AI”，点“预估用时与范围”，核对估计后点“确认预计用时并开始”。若要 AI，先保存自己的有效模型连接；模型请求按提供商规则计费。
7. 去“任务中心”打开新任务，看状态、实际新增数量及来源诊断。运行中可查看已经保存的结果。保持应用运行和电脑唤醒；完全退出应用会停止后台服务。
8. 打开“查看发现树、关系与证据”。先看起点与发现树，再点击账号、帖子和关系来源。对未判定类型保留未知；关注或提及本身不能证明组织隶属。
9. 若采集达到预算且仍有保存的线索，点“继续研究”并提高命中的累计上限；若只是 AI 分析尚未完成，在任务详情点“继续 AI 分析”或“仅重试 AI 分析”。这两个入口做的工作不同。
10. 研究到达终态后，从该研究生成报告。先用“证据整理”核对引用，再按需要生成 AI 分析。看到保存的报告和来源快照后下载；最后在设置里“备份研究数据”，确认文件确实下载完成。

### 2.1 怎么选初始预算

|用途|日期、层数与账号|关系、材料、滚动|运行时间与分析|
|---|---|---|---|
|首次核对流程|近 7 天；1 层；6 账号|30 关系；50 材料；5 次|900 秒；公开证据整理|
|一般主题研究|近 30 天；2 层；12 账号|60 关系；50–200 材料；10 次|1800–3600 秒；按是否配置 AI 选自动或规则|
|已有证据后继续扩展|沿原研究继续；总量和时长可改为 0 按范围完成|保留原层数、单账号读取与方向；正数时按累计条件|先预估再确认；按当前待执行线索继续|

预算越大，可能读取和保存的范围越大，也可能花更长时间、产生更多模型请求。它不是准确率、费用额度、余额检查或全网覆盖保证。先看实际材料质量和诊断，再加预算通常更容易发现问题。

## 3. 创建工作：共用输入与检索词

表中默认是**新建且没有恢复草稿时的页面初始值**。已有草稿、从账号跳入或从研究结果生成报告时，表单会带入此前值；提交前请检查。数值上限均为当前版本实际允许范围。

|页面参数|默认、可填范围|作用与设置方法|
|---|---|---|
|工作内容|探索账号与关系；可选采集公开材料|选择要保存的成果类型。要发现树与逐层关系选探索；只要新闻或帖子选采集|
|执行安排|单次任务；可选连续任务串|单次便于先核对流程；任务串用于按词组和日期分段排队|
|开始日期、结束日期|近 30 个自然日，含日本时间今天；开始不得晚于结束，跨度最多 3660 天|按日本时间 UTC+9，包含结束当天。近 7 天、近 30 天、本季度、上季度按钮填入日期；本季度可能含尚未到来的季度末|
|关键词|通常空；总长最多 1200 字，最多 12 组，每组最多 300 字|换行、逗号或分号分组；同一组内空格表示同时匹配。使用简明词，不手写平台检索运算符|
|词组关系|任意词组|任意词组：各组分别检索再合并去重；全部词组：合成同时匹配的条件，结果通常更窄|
|研究问题|可空，最多 1200 字|写希望回答的具体问题。为空时沿用关键词；非账号研究仍须有关键词|
|用户名|账号方式必填；X 为 1–15 个字母、数字或下划线，Instagram 为 1–30 个字母、数字、下划线或点|建议只填用户名，不含 @ 或完整主页 URL。它决定公开账号起点，不是登录账号输入|
|其他研究起点|空；文本最多 2000 字；连同主要账号合计最多 10 个去重起点|可分行或用逗号、分号填用户名或规范公开主页。只能填写已选平台；账号上限为正数时，起点总数不能超过该上限|
|相关性|研究相关（推荐）|按日本和平、反战主题与输入条件筛选；“按检索条件”更宽，所得材料需自行核对相关性|

关键词例子：第一行 `反戦 デモ`，第二行 `平和 集会`。选择“任意词组”时，分别查“反戦且デモ”和“平和且集会”；选择“全部词组”时，要求这两组词一起参与检索。实际平台仍可能返回有限或不精确的结果。

“生成相关词”是本地建议；“AI 扩展研究词”是单独的模型请求，会使用已配置连接。建议供点击加入，不自动替换原词，可以“撤销最近添加”。即使随后研究选规则整理，单独点击 AI 扩词仍会调用模型。

草稿会在输入后自动保存，关闭创建窗口可稍后继续。提交得到服务确认后，才清除相应未改变的草稿；提交失败保留输入。多个窗口修改同一草稿时按页面冲突提示选择，先核对两份内容再保存。

## 4. 普通采集公开材料

在研究工作台选择“采集公开材料”。可选公开新闻、RSS、X / Twitter、Instagram。新闻与 RSS 不要求社媒会话；X、Instagram 需要相应采集组件和已验证会话。

|参数|新表单默认与范围|作用与建议|
|---|---|---|
|来源|公开新闻，或入口带入的来源|选择要读的平台。RSS 需要填订阅地址|
|采集方式（社媒）|关键词发现；另有主题标签、指定公开账号|关键词发现找主题材料；主题标签填单个标签，不含空白，可省略 #；账号方式读明确账号|
|RSS 地址|空；最多 2000 字的公开 HTTP(S) URL|填写实际订阅源地址，而非普通网站首页|
|最多保存条数|30；整数 1–100|本次保存上限；不是最低取得量，去重和筛选后实际新增可能更少|
|最多访问账号（社媒）|3；整数 1–10|本次普通采集访问账号的上限，与研究的累计账号范围不同|
|每页最多滚动（社媒）|5；整数 1–20|允许页面加载更多内容；无新内容、访问限制或结束时可提前停止|
|发现公开关注关系|默认关闭|需要额外记录公开关注对象时开启；不授予核验，也不推断隶属|
|关注关系上限|开启时初始 10；整数 0–50；关闭时提交 0|本次额外保存关注关系的总上限|
|相关性|研究相关（推荐）；可选按检索条件|普通采集使用正文规则，不调用 AI 筛选。宽模式便于先取得候选再人工判断|

普通采集没有可填写的整任务运行时间字段。材料保存到“资料库”，公开关注记录可在账号的“关系”或“账号关系图”核对。关键词发现命中的作者不自动成为已核验账号。

日期不明的社媒记录可能被排除并计入诊断；新闻日期不明时会明确标记。缺少日期不应补成今天。遇到零条材料，先看来源、会话、日期、滚动和筛选诊断，不能把零条直接解释为“该账号没有活动”。

## 5. 探索账号与关系

从关键词新闻线索或明确公开账号出发。关键词方式可选公开新闻、X、Instagram 中的一项或多项；初始只勾选新闻。指定账号方式只用所选社媒平台，关键词可留空。深度研究不提供 RSS 或标签起点。

**账号、关系、材料的总数量及总时长默认填 0，表示按设定范围完成，不额外施加这项提前停止条件。** 日期、探索层数、单账号读取、每页滚动与每方向邻居数仍定义研究范围；来源耗尽或连续没有新内容可以自然结束。0 不等于全网无限抓取，也不会强行取得目标数量。

|参数|初始值、范围|作用与设置方法|
|---|---|---|
|检索入口|公开新闻开启，X、Instagram 关闭；至少一项|只访问选中的平台；发现未选平台的链接只保存线索|
|向下探索层数|2；整数 1–8|起点为第 0 层。控制递归探索的层数；建议先 1–2 层核对候选质量，再增加|
|最多探索账号|0；整数 0–10000|0 不额外限制整个研究的累计账号数量；正数是累计上限，包含起点|
|最多记录关系|0；整数 0–100000|0 不额外限制累计观察关系；正数是累计上限，不是互动次数或隶属数量|
|最多保存条数|0；整数 0–1000000|0 不额外限制总材料数；正数由各账号和入口共用，不是每账号各保存这么多|
|每页最多滚动|10；整数 1–5000|每个页面允许加载更多内容的次数；来源结束、没有新内容或访问限制可提前停止|
|单账号 / 单次查询最多读取条数|1000；整数 1–50000|定义每个账号或查询分支的读取范围；大值会显著增加逐条阅读与报告时间|
|每个方向最多展开邻居|100；整数 1–5000|每个账号在一个方向可读取的候选数量；多个方向和多层会扩大总规模|
|单个任务运行时间上限（秒）|0；允许 0 或整数 30–2592000|0 按范围完成；正数为本次研究采集与分析的总时间条件，最高 30 天。快捷按钮也可选按范围完成|
|沿关注账号展开|开启|追查该账号关注的公开对象|
|沿被关注账号展开|关闭|追查关注该账号的公开对象，通常分支更多|
|沿帖子提及账号展开|开启|沿原帖明确提及继续；至少选一种关系|
|关系分析方式|自动 · 有 AI 时增强分析|自动在配置可用时用 AI；公开证据整理不调用 AI；AI 分析要求连接配置。失败保留证据与成功批次|

填写后先点“预估用时与范围”。预估不采集、不入队，也不要求为预估先登录；查看数量级、预期时间范围、范围限制与费用提示后，再点“确认预计用时并开始”。改参数或日期会使旧预估失效，需要重新预估。实际开始仍须满足所选来源的会话与组件要求。

AI 会依据已保存公开材料对候选账号逐层排序。指定账号且关键词留空、不另设主题过滤时，最多 12 轮排序；其他主题研究最多 3 轮探索决策。只有存在足够候选和依据才请求模型，失败保留候选并回到规则顺序。这是当前探索调度方式，不能把排序、语义相似或结构角色当成政治身份或组织隶属。

达到用户填写的正数条件时，已有结果和待执行线索保存，并说明是哪项导致停止。0 条件不会因旧的 40 账号、200 关系默认值提前结束。仍未读完的分支、平台阻断、日期未知或未通过的 AI 分析会按实际缺口显示；不会为了显示“完成”隐藏这些情况。自然读完所选范围且分析步骤完成，可正常显示“已完成”。

结果分别展示已保存账号、关系、材料，待探索、待准入、待保存及未完成查询。旧任务没有保存候选地址或分支时只能标为未知；计数不能恢复未保存的线索。想从关键桥接账号再深查，可从节点打开预填表单，核对范围并预估后启动。

## 6. 连续任务串

任务串将较大的词组和日期范围拆成有限任务，顺序排队。它用于组织执行，不是每天自动运行的定时任务；每个子任务仍保留自己的范围和来源诊断。

1. 创建表单选择“连续任务串”，填写来源、词组、日期和每个任务的读取范围。
2. 填整体材料目标，点“预览任务串”，核对任务数量、各词组、日期窗口、每段份额及最大可能保存数量。
3. 修改输入后重新预览，确认当前有效预览再创建。
4. 在任务中心查看批量任务串及各子任务，避免重复创建。

|参数|初始值、范围|含义|
|---|---|---|
|任务串标题|可空；最多 160 字|为空使用系统标题，用于区分主题和日期|
|整体材料目标|1000；整数 1–1000000|整串的规划目标，实际去重保存可能少于目标；任意词组时不能少于词组数|
|子任务数量|预览计算；最多 200 个|限制单次规划的队列大小；不是历史任务总数限制|
|每个任务最多保存条数|普通采集 1–100；研究任务串使用正数，最多 1000000|预览必须有正数份额才能分段；从单次研究切到任务串时，原 0 会换为规划用的正数|

任意词组先分配目标再按每组日期拆出不重叠窗口，优先近期；全部词组作为一组条件。日期天数不足时，预览会说明可能数量低于目标。重复材料、来源耗尽和平台限制也会使实际新增少于计划。

任务串“已结束”包括失败、取消、中断和部分完成，100% 表示子任务都到终态，不表示全部成功。重试未完成任务创建新重试串；成功任务保留。只有 AI 待完成时明确显示仅续 AI 的入口；命中用户的累计数量条件时，应进入研究结果调整条件，不能靠重复同参数任务突破。

## 7. 任务状态、取消、重试与继续

任务中心每页 20 条，任务串每页 10 条。打开任务详情可看创建、开始、结束时间，进度、实际结果、来源诊断及执行事件。按钮是否可用以当前终态和保存的工作为准。

|状态|怎样理解|下一步|
|---|---|---|
|排队|已创建，等待执行|避免重复提交；需要时取消|
|运行中|正在访问来源、处理材料或分析|看诊断与保存进度；可请求取消，等待当前操作结束|
|已完成|本次任务流程结束|核对实际材料、覆盖和保存报告；仍不保证完整社会事实|
|部分完成|已有成果，但预算、平台或分析造成缺口|读停止原因，选择继续研究或仅续 AI；保留已取得结果|
|失败|本次未完成所要求步骤|修复会话、连接或输入问题后按入口重试|
|已取消|用户取消后停止|已保存材料仍在；不要以为取消会回滚|
|已中断|应用、服务中断或恢复备份等导致停止|确认当前没有活跃同研究任务，再按可用入口重试|

### 7.1 三种后续操作分别做什么

|入口|执行内容|可改哪些参数|
|---|---|---|
|重试任务|为失败、部分完成、取消或中断创建有原记录关联的新任务；按实际恢复条件执行|沿原参数；不会自动增加已经用满的硬预算|
|继续 AI 分析 / 仅重试 AI 分析|仅处理保存证据的待审部分，复用同证据范围的成功批次，不重新采集|页面不修改原采集范围；仍可能产生新模型费用|
|继续研究|沿同一研究保存的账号、材料、关系、查询或分支继续采集|只改账号上限、关系上限、材料上限、本次时长四项|

“继续研究”四项范围分别为账号 **0–10000**、关系 **0–100000**、材料 **0–1000000**、本次时长 **0 或 30–2592000 秒**。0 表示不额外施加该项总量 / 时长条件；正数不得低于已保存数量或不允许降低的当前范围。命中某项正数条件时须提高或将该项改为 0。前三项为整个研究的累计条件，时长为本次继续条件。先预估待执行范围，确认后创建；预估绑定当前研究和当前任务，期间变化需重新预估。

继续研究保留原关键词、来源、日期、探索层数、滚动、分析方式及关系选择，不能在此扩大单个账号的读取范围。想改这些条件，创建明确的新研究。同研究已有排队或运行任务时不能再创建一个后续任务。只有 `partial` 标签不能证明可继续；没有保存的待执行线索时页面会说明原因。

AI 覆盖会显示“成功分析 / 可用证据摘录、待审条数、成功批次、续用批次”。摘录审完也不表示全部公开原文已读，更不等于结论自动正确。模型语法或输出校验失败时会保留可安全恢复的最终内容或明确遗漏原因，不把格式修复当作事实核验。

### 7.2 常见失败怎么处理

|提示或现象|处理顺序|
|---|---|
|会话缺失、失效或登录挑战|先去设置检测；必要时在正常浏览器完成平台要求，再同步并验证。不要反复创建同类采集任务|
|来源耗尽、无新内容、日期未知或大量筛除|核对账号、日期和相关性；必要时缩短范围或试宽筛选。保存诊断，不推断“没有活动”|
|材料、账号、关系上限停止|看待执行线索；在“继续研究”提高命中的累计上限，或以选中账号创建新范围|
|模型余额不足（HTTP 402）|已完成批次和待处理证据保留；由用户在提供商处补充余额后，回到正常分析重试入口。应用不会自动查询余额或无限重试|
|模型鉴权、HTTP、超时、截断或未完成输出|根据明确错误核对连接或等待服务恢复；先看已有任务是否已结束，再重试。配置存在不等于请求成功|
|页面提示尚未确认创建或保存|先刷新任务中心核对是否已经有新记录，再决定下一次动作，避免重复工作|
|报告没有保存结果|去任务详情看最终错误和待处理步骤。来源阅读完成、进度高或草稿可见，都不能替代保存报告|

## 8. 资料库：阅读、检索、导入与公开正文

资料库每页 25 条。点击标题读保存的完整正文、来源、日期和证据信息；使用“查看原始来源”回到公开页面，区分保存正文、摘要、网页后来变化和当前访问限制。

|筛选参数|默认与作用|
|---|---|
|搜索资料|空；查标题或正文关键词|
|资料类型|全部类型；可选新闻、社媒|
|主题|空；按主题名称筛选|
|来源|空；按来源名称筛选|
|开始日期、结束日期|空表示不限定该端；日本时间 UTC+9，包含结束当天；有范围时未知发布时间需按页面诊断核对|

新闻详情中的“出版方原文地址（聚合器资料需填写）”最多 2048 字。填实际出版方的公开正文 URL，再点“读取公开原文”；有旧正文时可“重新读取公开原文”。这是一个后台任务，成功读取和版本历史可在详情核对。访问失败或付费、登录墙不能当作已经读完全文；原来保存的内容和版本不会因此被猜测替换。

### 8.1 导入已有公开材料

点击“导入资料”，选择 UTF-8 JSON 文件（最多 **10 MiB**），或粘贴 JSON 文本。接受记录数组或带 `items` 数组的对象；每次 **1–2000 条**。常用字段为标题 `title`、公开地址 `url`、保存正文 `content`、类型 `type`（news 或 social）、来源名称 `source_name`、发布时间 `published_at`；可带主题、实体、地点及已有账号关联。

下面只是格式示例，并不是实际采集记录：

```json
{
  "items": [
    {
      "title": "公开活动报道（格式示例）",
      "url": "https://example.org/public-news",
      "content": "粘贴你实际取得并可核对的公开正文。",
      "type": "news",
      "source_name": "示例来源",
      "published_at": "2026-10-01T09:00:00+09:00"
    }
  ]
}
```

日期未知就留空，不补成当前时间。导入后查看新增、更新补全、仅重复和拒绝原因；相同 URL 会做去重或补全，不能把“已处理”条数都算新增。普通导入不会把自称、账号类型或自填可信标记变成核验事实。API Key、密码和浏览器会话不属于研究材料，不要粘贴到这里。

## 9. 组织与账号：登记、类型、核验和相关性

账号页每页 30 条，可搜索名称、组织或用户名，核验状态筛选为全部、待核验、已核验、已排除。卡片上的“关系”查看保存的方向、首次与最近观察时间及证据；“采集”带入 X 或 Instagram 的指定账号表单。

### 9.1 基础账号资料

|字段|范围、初始值|填写与影响|
|---|---|---|
|显示名称|必填，最多 160 字|用公开名称，无法判断主体时保留中性名称|
|用户名|界面必填，基础档案最多 200 字|这是通用来源档案；实际 X / Instagram 采集仍分别遵守 15 / 30 字符规则|
|平台|新增为 Twitter / X；另有 Instagram、YouTube、Mastodon、RSS、其他|能登记的平台不代表都有自动采集器；当前社媒采集入口为 X、Instagram|
|公开账号地址|必填，最多 2000 字，HTTP(S)|保存准确主页，不含用户名密码；改地址会回到待核验并清除旧核验依据|
|所属组织|可空，最多 200 字|辅助备注，不能仅凭填写授予组织身份或隶属|
|标签|可空，最多 30 项；逗号分隔|用于整理，标签不是核验依据|
|核验依据地址（人工核验）|核验时必填，公开有效 HTTP(S) 地址|先打开并核对准确账号回链或可信证明，再保存|

新账号为待核验。已有资料、关系或研究关联时，平台或用户名不能直接改成另一个主体，应新增账号保留旧证据归属。“排除”保留账号与材料，避免继续作为正常研究对象。

### 9.2 三件事情必须分别看

|标记|回答的问题|不能证明什么|
|---|---|---|
|组织 / 个人 / 未判定|公开账号主要由哪类主体使用，有何类型依据|不证明所有关注者属于该组织，也不证明发帖内容正确|
|待核验 / 已核验 / 已排除|主页是否有准确、可信的身份依据及人工状态|蓝标、自称或 AI 猜测不能直接替代核验|
|重点 / 桥接 / 外围|在当前有来源关系集合中的结构位置|不证明实际影响力、协调、背书或隶属|

在“账号关系图”点击账号，可查看类型依据、限定范围和链接，并进入下列人工更正入口。

|类型更正参数|默认与范围|作用|
|---|---|---|
|账号类型|当前类型；组织、个人、未判定|没有可靠依据选未判定。不要按用户名、粉丝量或关注关系猜类型|
|类型说明|空或旧说明；最多 1000 字|写支持或保留未知的原因|
|公开类型依据|最多 5 个独立 HTTPS 链接|不用 X / Twitter / Instagram 自身作为独立官网来源；地址不含凭据，仅默认 HTTPS 端口或 443|
|人工锁定|默认开启|阻止自动来源类型覆盖人工判断；解除锁定不自动变为组织或个人|

### 9.3 登记可信来源与自动核验

点“登记核验官网来源”，最多登记 **5 项**。每项填写公开 HTTPS 地址（最多 2048 字）、来源名称（最多 200 字）和该目标账号的类型（默认未判定）。只有已核对的独立官网、组织网站等才应登记为可信来源；填写组织或个人前，确认该来源说明的是当前目标。

登记来源或相关公开资料更新可排入自动核验。它在独立后台队列检查有限公开页面，不阻塞普通研究队列；单纯打开账号列表不会触发网络核验。进度会显示排队、核验中、部分完成或失败，可点“查看核验执行记录”。

“核验候选账号”每次最多检查 **20 个**候选；可对单个账号“自动核验此账号”。单账号的“独立公开依据网页（可选）”在本次检查中按用户明确提供的可信依据使用，准确回链时可能授予核验；请先自行核对来源。它**不会永久登记为可信官网锚**，长期依据另用登记入口。检查有缓存和有限页面范围；页面未找到回链、来源不可用或冲突时保留待核验，不能认定账号是假的。

只有已登记可信锚、已核对的精确来源，或用户明确提供的本次依据，准确回链到当前主页，才可授予自动核验。简介中未经可信来源核对的自填网址回链属于候选证据，需要人工确认。网站曾为另一个账号登记，不会把登记者的组织或个人类型传播给当前账号；因此一个已核验账号仍可能类型未判定。

### 9.4 手工控制研究相关性

“更正研究相关性”有三个选择：**恢复默认规则、明确纳入研究、人工排除研究**；原因最多 1000 字。人工排除保留账号、类型、核验状态、公开材料和原始关系，只影响默认展示和继续拓展。恢复默认规则删除人工覆盖，通用平台仍可能被默认隐藏。

当前默认隐藏的通用精确账号为：X 的 `youtube`、`teamyoutube`、`google`、`instagram`、`x`，以及 Instagram 的 `instagram`。这是很小的精确名单，不按粉丝量或相似名字猜测；`youtube_japan`、Instagram 的 `youtube` 不会因此自动隐藏。

在图中勾选“显示通用账号”可以核对这些平台号连接的原始链，它们仍不参与重点或桥接排名，人工排除不会由此开关恢复。确实主动研究一个通用平台时，明确指定为起点或人工纳入可保持其研究用途；已经人工排除的账号不会仅因被选中或设为起点而复活。原始公开记录不因默认过滤而删除。

## 10. 发现树与账号关系图

研究结果中的“发现树”回答“从哪个起点、通过哪条公开线索找到这个账号”。账号关系图回答“保存的哪些账号之间有可追溯关系”。跨研究图是有限展示集合，最多显示 **300 账号、1000 关系**，未展示的来源记录和覆盖提示要一并看；账号关系记录可分页，不能把当前图当全部保存资料。

|图上控制|初始值、可选值|怎么用|
|---|---|---|
|查找账号、平台、关系类型|空 / 所有平台 / 全部关系|按名称用户名、X / Instagram 或关系类别缩小显示；只改视图，不重新采集|
|显示层级（研究结果）|默认所有层级；可显示到第 0、1、2 层|按原研究从起点记录的发现深度筛选，第 0 层只看起点；不是距当前选中账号的跳数|
|关系起点|选中账号或首个显示账号|选择下面方向、跳数及路径的起点；可点“以选中账号为起点”|
|关注方向|全部关系；我关注；关注我|“我”是关系起点账号，不是你的登录账号。后两项只沿已保存的关注关系，不把提及当关注|
|关系跳数|全图；1、2、3 跳|强调距当前关系起点的公开路径，其他节点保留淡化；方向从全图改为关注方向时，初次会带入 1 跳|
|结构层级|全部层级；重点、桥接、外围|强调当前有来源结构，节点详情解释依据。外围仍可继续追查|
|路径终点|不指定终点；当前显示账号|选择另一账号，查看最多 3 跳的最短有来源路径；每一跳可点关系及来源|
|显示通用账号|关闭|恢复通用平台账号的原始链供核对，不能恢复人工排除|

“全部关系”可逆向浏览已保存的关系，但箭头始终保留原始观察方向。切换我关注或关注我时，路径按真实关注方向走；点每一步的证据核对。未找到路径只表示当前方向、跳数、显示范围及证据内未找到，不表示现实中没有关系。

“重点”表示当前来源关系中连接较多；“桥接”表示移除该节点后会分开已有支路；“外围”表示其余或孤立位置。结构会随筛选和未展示资料变化。相邻两个“组织账号”也可能属于同一组织实体，不能因此称作跨两个不同组织的桥接事实。

当前类型轮廓为组织绿色圆角方形、个人棕色圆形、未判定灰蓝菱形；悬停或选中用外围环强调，保持类型色。已核验账号另有内部白色勾，不用改变类型色表示核验。图的布局距离、线条视觉或节点位置不表示关系强度。分析结论中的已观察关系、可能联动、隶属线索要分别看原始来源与推断限定，不能用“更近”“更粗”当事实证据。

保留现有动效操作：拖动账号会推开附近节点，松手后整理到稳定；拖动背景平移；滚轮或放大、缩小按钮缩放；“适应画布”调整视野；双击固定或释放节点，方向键可移动并固定；“暂停布局动效”只暂停视觉；“重置布局”重排位置，不改账号或关系。切换强调会尽量保留位置和视野。

点“以起点账号继续研究”会预填该公开账号的新研究表单。先检查来源、日期与预算，再发起；它不会悄悄加大旧研究的 3 层上限。

研究结果下方“关系分析与隶属线索”还会区分公开声明、公开观察和待复核的推断。点“确认证据”时填写“支持该关系的公开证据链接”（确认时必填），以及“核对说明”（最多 1600 字）；说明该来源究竟支持什么，不把关注变成隶属。证据不能支持时可“排除此判断”。人工确认只记录该条判断的复核，不自动改变账号主体核验或所属组织。

## 11. 日本活动地图与人工核对

情报总览的“各地活动数量占比”统计实际活动，文章地名提及另有展示。新闻写到东京，不等于东京发生了一场活动；未经核对的候选不进入已核对活动分母。

|地图参数|默认与作用|
|---|---|
|活动日期 · 从、至|空；按实际活动日期筛选，不是文章发布日期；开始不得晚于结束|
|活动记录|已核对活动；可切换待核对线索|
|都道府县选择|全国；点地图或排行选地方，点击“查看全国”清除|

占比 = **该地已核对且已定位的去重活动数 ÷ 所选活动日期范围内全国已核对且已定位的去重活动数**。未定位活动保留在记录中，暂不进入分母；没有可用分母时显示无数据，而不是完整社会活动为零。地图反映当前取得并核对的公开样本，不能代表日本全部社会活动。

在资料详情点击“标记并核对活动”，或在地图候选中点击“核对这场活动”。

|核对字段|范围与填写方法|
|---|---|
|活动名称|必填，最多 260 字；具体到一场活动|
|实际活动日期|确认时必填；按原文核对，不能直接用报道发表日|
|实际举办地|47 个都道府县或暂时无法定位；没有依据留未定位|
|保存原文中支持活动的摘录|必填，最多 2000 字；从已保存正文选支持活动的原句，不自行添加材料外事实|
|重复报道合并|默认单独活动；同名称、摘录、日期和地点可自动合并，也可明确选已有同一活动|
|核对说明|可空，最多 1600 字；解释日期、地点或合并判断|

点“保存已核对活动”后按去重活动更新地图；不是活动或证据不足，可“排除此线索”。同一场活动有多篇报道，应合并来源，不能按文章条数扩大活动数量。

## 12. 研究报告：生成、阅读与导出

从“研究报告”生成，会按资料库日期与类型选择材料；从某个研究结果点击“生成研究分析报告”，会绑定该研究保存的版本、目标和覆盖边界，避免用后来更新的材料冒充原研究。研究还在排队或运行时，先等终态。

|报告参数|初始值与范围|作用|
|---|---|---|
|报告标题|可留空自动生成；最多 160 字|只改标题，不改变证据范围|
|报告模式|普通资料入口为证据整理；研究入口已配置 AI 时为 AI 分析，否则证据整理|证据整理不调用模型；AI 分析使用已配置模型读取与综合保存证据，并核对引用|
|开始日期、结束日期|近 30 天，或该研究原范围；日本时间含结束当天|按材料日期选普通报告范围；研究报告仍受保存研究范围限定|
|包含新闻、包含社媒|默认均开启；至少选一项|限制所选材料类型；不是新增采集指令|
|报告最长运行时间（分钟）|0；整数 0–43200|0 不额外限制报告分析总时长；正数为本次阶段的时间条件，最多 30 天。单次网络请求仍有超时|

报告没有可填写的字数或费用额度。资料充分时会组织较完整的分析，信息不足则应明确不足，不能为凑篇幅编造。时间、材料条数和模型上下文均不能保证准确率、余额足够或固定价格。

普通资料库报告的所选范围超过 **5000 条**时会拒绝，请缩小日期范围；这是来源选择边界，不能在报告表单中提高。普通报告可能尝试读取可直接访问的出版方公开正文；研究报告使用该研究已保存的版本，不再次把当前网页覆盖进旧研究。新闻摘要、读取失败、账号候选和证据不足会作为边界说明；候选社媒不能直接撑起已核验主体的主要事实结论。

生成后去任务中心，只有出现报告结果且能“阅读生成报告”，才可确认保存成功。在“研究报告”中阅读正文，核对每个引用和“保存的来源快照”，下载为 Markdown。报告列表每页 20 条。

研究结果上的“下载研究摘要”“导出关系与证据”是已有研究的导出；它们不代表已经生成新的 AI 正文报告。原材料之后清理或网页变化，历史报告独立快照保留，报告不会被静默改成另一份证据范围。

## 13. 能力、AI 连接、平台登录与浏览器连接

### 13.1 AI 连接设置

桌面应用可在“能力与设置”保存连接。浏览器模式页面不保存 API Key；无 AI 时，普通采集、公开证据整理和已有资料仍可使用。请等待排队及运行任务结束，再修改连接。

|设置项|默认与范围|填写与影响|
|---|---|---|
|服务地址|`https://api.deepseek.com`；最多 2000 字，有效 HTTPS URL|按自己的服务商说明填写服务入口，不填网页登录地址或带用户名密码的 URL|
|模型名称|`deepseek-flash`；最多 160 字，去空白后非空|源码默认名称不保证提供商始终提供该模型；按自己可用模型填写|
|API Key|密码框为空；最多 4096 字|由用户自己填有效值，保存不回显。已有连接时留空保留旧值，填新值替换|
|清除已保存的密钥|默认不勾选，已有连接时显示|勾选会清除，优先于同时填入的新值|

点击“保存 AI 连接”只更新配置，不调用模型，也不是余额或真实连通性测试。系统加密存储不可用时会禁用保存；读取原加密连接失败或运行状态未确认时按明确提示重新填写或重新打开应用。不要把密钥写进研究问题、导入资料、报告或共享截图。

“已配置”只表示连接配置存在，实际成功和错误看任务中心。“打开数据目录”“打开运行日志”是本地查看入口，不能替代数据库备份。

### 13.2 社媒登录与会话验证

1. 在设置的对应平台点“检测并复用已有登录”。这会创建登录检测任务；先验证已保存会话，必要时按页面提示同步正常浏览器中已有登录。
2. 没有可用登录时，点“在系统默认浏览器登录”，在正常平台页面由自己完成登录、验证码等要求。
3. 回工作台进行对应的会话同步与检测。仅打开浏览器或登录网页，不代表工作台采集会话已保存。
4. 任务成功并显示会话已验证后，再创建采集。会话仍可能因退出、到期或平台挑战失效，失效后重新验证。

页面提示 X 与 Instagram 可尝试复用默认 Firefox 中已有会话；以实际验证结果为准，不保证任何浏览器配置都能自动识别。X 另有显式“同步 Firefox 会话”：选“Firefox 配置”，点“导入并验证 X 会话”。配置名称只区分本机资料，不能证明登录者身份；成功验证后才更新工作台，失败或取消保留原会话。显式 Firefox 导入入口仅支持 X。

若使用应用提供的手动登录窗口，任务最多等待 10 分钟；取消登录任务会结束等待。平台“采集会话已验证”与研究账号“主体已核验”回答不同问题，不要混用。

### 13.3 Chrome / Edge 本地会话连接

此入口需要用户自己安装并同意连接本项目提供的会话扩展；本手册不表示扩展已经在你的浏览器安装或完成真实配对。可使用交付中的 `browser-extension` 目录，在 Chrome 或 Edge 扩展管理页面打开开发者模式，选择“加载已解压的扩展程序”并指向该目录；只使用本项目交付内容。

1. 在正常 Chrome / Edge 登录 X 或 Instagram。
2. 在工作台选择该平台，点“连接已登录 Chrome / Edge”，生成本机配对链接。
3. 打开“PEACE ATLAS 会话连接”扩展弹窗，粘贴“本地配对地址”，点“连接并验证会话”，核对并同意所选平台与本机连接权限。若复制按钮不可用，手动选中该地址复制。
4. 等实际验证，然后关闭工作台配对窗口并点“检测并复用已有登录”。配对本身不等于登录成功，必须实际验证并保存。失败时看提示，保留原工作台会话。

配对链接有效 **5 分钟**、一次使用，不要转发。连接令牌限当前工作台进程，最长 **24 小时**；重启、换端口或到期后需要重新配对，通常无需重新登录平台。扩展的“立即验证”手动检查，“断开连接”停止后续同步和撤销扩展连接，不会随之删除已保存的工作台会话。

扩展不需要密码或手工复制 Cookie，也不会发帖、关注或改变正常浏览器的登录。自动同步和平台可用性仍受到期、验证码和访问限制影响；用户应看实际验证结果。

## 14. 备份与恢复研究数据

### 14.1 备份

在“能力与设置”点击“备份研究数据”，保存下载的 SQLite 文件。它包含已提交的资料、账号、关系、研究与分析检查点、报告快照、人工核对、任务、任务串和已同步草稿；**不包含浏览器登录会话、AI 密钥、日志或尚未同步的本地输入**。

在下载列表确认完成，保留带日期的多份备份。备份按钮生成独立一致的数据库文件，使用这份完整下载文件即可；不要把某个运行中数据库文件单独复制后当作一致备份。备份繁忙或失败时原资料不变，等明确结束再重试。

### 14.2 桌面恢复：优先使用正常按钮

1. 先备份现在的资料，核对要恢复的是哪一天、哪台工作台的数据。
2. 点击“恢复研究备份”，在原生文件窗口选择本工作台生成的独立备份。
3. 阅读结构、数量与覆盖检查提示，确认选对文件，再在原生窗口确认。取消时不替换当前资料。
4. 应用检查后暂停服务、自动存档恢复前的数据库及配套文件，再替换研究库并重新连接。
5. 恢复成功后查看资料、账号、研究结果和报告；备份中的排队、运行任务会标为中断，需在任务中心手动重试。

研究恢复不替换当前浏览器会话与 AI 连接。在新设备使用备份时，登录和密钥要由用户分别配置。任何 SQLite 文件都不等于有效工作台备份；预检不通过时按提示处理，不能跳过结构和关联检查。失败时保留回退存档和明确诊断，不凭“选择了文件”认定已经恢复。

### 14.3 只在必要时手动替换

界面无法恢复且需要手动处理时，先“打开数据目录”记下位置，**完全退出应用并停止本地服务**，复制整个数据目录作回退；把旧 `workbench.sqlite3` 及可能存在的 `workbench.sqlite3-wal`、`workbench.sqlite3-shm` 一起移到回退位置，再把独立下载备份复制为 `workbench.sqlite3`。不要把旧 WAL / SHM 留在新数据库旁。重新打开后核对结果，保留旧副本。

仅这种手动文件替换方式下，原运行任务会中断，原排队任务可能按正常队列继续；桌面恢复按钮会把两者都中断、等待人工重试。优先用桌面按钮，避免恢复后意外续跑。完整技术说明另保留在原有备份文档中。

## 15. 手动资料清理与回收站

资料库中的“清理资料”是人工保底工具。先逐条核对来源、内容和重复情况，再选记录，不因 AI 判断或关键词相似就整批删。清理前等普通采集与研究结束或取消，避免边采集边改变其证据。

1. 进入清理页，按标题或正文筛选。
2. 勾选要处理的记录。**“选择本页全部”仅本页 25 条**，不会选中其他页或全部筛选结果。
3. 点击“移入回收站”，查看明确数量、标题、来源和影响，填写原因后确认。原因必填、最多 500 字；默认理由可改成自己的核对说明。
4. 回收站资料不参与普通检索、新报告或活动地图，但保留可恢复记录。
5. 在回收站选同样明确的记录，可预览并“恢复”，保留原编号和来源；恢复原因同样必填。
6. 确实需要彻底删除时，只能选已经在回收站的记录，预览、填写原因，再勾选“不可恢复”确认。它会删除源记录及历史版本，之后不能从回收站恢复；已有报告的独立快照保留。

预览后资料或状态发生变化，应用会要求重新预览；取消不执行。恢复与彻底删除也是当前页明确选中范围，不能把按钮理解为清空全库。

## 16. 每次研究结束时的核对清单

- 任务确已到终态，实际新增数量、停止原因和各平台诊断已经读过。
- 研究起点、日期、所选平台和预算与目的相符，剩余线索或待审证据数量明确。
- 关键关系逐边有来源，类型、核验、推断与结构层级分别表达；材料不足保留“未知”或“不足以判断”。
- 活动日期与地点按原文核对，同活动重复报道已合并；地图分母和未定位数量清楚。
- 报告已保存、能打开并核对引用；研究摘要与 AI 正文报告没有混为一件事。
- 报告及研究备份已下载完成，知道如何在正常入口继续或恢复。

## 17. DSH 工具分析：设置、取证与失败后续跑

DSH 工具分析在逐条阅读保存材料之后，让 AI 围绕原研究问题自主选择证据工具、比较说法、追查已观察路径，并整理候选解释与缺口。它只读本报告的保存范围，**目前不会联网扩采新账号，也不会更改账号核验状态或新增正式关系**。如果需要采集其他账号或扩大日期、来源，请按第 5、7 节创建新研究或使用允许的“继续研究”。

### 17.1 创建报告时怎么选择

先在“能力与设置”确认自己的 AI 连接已配置，并查看 DSH 运行工具是否可用。已配置、已安装与真实分析成功是不同状态；提交后到任务中心看实际结果。

从已保存研究点击“生成研究分析报告”，表单带入原研究问题、日期与材料范围。AI 连接和 DSH 工具都就绪时，默认使用“AI 分析”和“DSH 工具分析 · 主动查证与比较”，最长运行时间默认 **0（按范围完成）**，决策和工具次数默认 **0（不另设次数上限）**。没有 AI 配置时使用证据整理；有 AI 但 DSH 工具不可用时可用标准 AI 分析。

从普通“研究报告”页面点击“生成报告”，默认仍是“证据整理”，最长运行时间为 **0**。若要用 AI，自己切换报告模式；普通入口不会自动改成 DSH。只有 AI 报告显示“AI 调查方式”，证据整理不调用 DSH。

|参数或方案|初始值与可填范围|怎么理解与设置|
|---|---|---|
|AI 调查方式|标准分析，或 DSH 工具分析；研究入口满足就绪条件时默认 DSH|标准分析执行逐条阅读与报告复核；DSH 在相同保存证据范围内增加自主工具调查|
|最多 AI 决策轮数|研究入口 0，普通入口 24；允许 0 或整数 2–4096|0 不额外限制 DSH 决策次数；正数为同一输入恢复链的累计次数条件。一次决策可调用多个工具|
|最多工具调用数|研究入口 0，普通入口 64；允许 0 或整数 2–65536|0 不额外限制 DSH 工具次数；正数为同一输入恢复链的累计次数条件。仍只允许七种保存证据工具|
|最长运行时间（分钟）|0；整数 0–43200|0 按范围完成；正数为报告分析总时间条件，不是费用额度，也不保证该时间内成功|
|需要比较较多材料时的起步建议|32 轮决策 / 96 次工具 / 120 分钟|这是可手动填写的建议组合，不是默认值或完成保证；先看已有正文阅读、取证记录和失败原因，再决定是否提高|

决策次数和工具次数仅是 **DSH 阶段的技术累计上限**，不包含前面的全文逐条阅读，也不包含后面的最终综合、报告生成和引文复核。它们不是模型收费预算、余额、Token 总额度或所有 AI 请求的总次数。模型按提供商规则计费；调高次数或时间可能产生更多请求，不能据此算出固定费用。同一输入未完成时续跑，已用次数仍计入累计值；只提高上限并不改变原研究问题或证据。

### 17.2 运行顺序：先全文阅读，再工具调查，最后保存报告

以报告范围内有 **601 条已保存材料**为例，运行顺序是：

1. 先逐条阅读这 601 条保存材料，长正文按连续片段读取，并核对所用摘录是否确实出现在保存原文中。成功的阅读批次会保存；601 条材料须完成对应的全部正文片段阅读，不能用 DSH 读过几条来替代。
2. 正文阅读完成后，DSH 围绕原目标调用下方七种工具，按需要再次读证据、比较来源、检查账号及有向路径，形成有引用的候选判断、调查重点、证据缺口与下一步线索。
3. 继续生成研究报告，把来源说法、已观察事实、模型推断与不足分别表达，并进行引用和报告复核。DSH “取证完成”只表示工具阶段结束，仍需完成后面的报告步骤。
4. 到任务中心确认任务终态、报告已保存且能“阅读生成报告”。再核对正文引用与“保存的来源快照”，展开“DSH 工具取证记录”，最后下载 Markdown。全文阅读进度完成或工具调用已有结果，都不能单独证明报告已经保存。

这里的 601 条是顺序说明示例，不是每次任务必须有的条数，也不宣称某个真实任务已完成 601 条分析。实际数量、逐片覆盖与终态以该次任务保存记录为准。保存正文可能是摘要或有明确截断的公开片段；读完保存内容不等于已取得外部页面所有原文。

### 17.3 七种工具分别能证明什么

工具由 DSH 按问题自主选择，用户无需手工输入工具命令。报告中的“DSH 工具取证记录”可按以下名称核对：

|取证记录名称 / 工具标识|读取或处理什么|边界与核对重点|
|---|---|---|
|浏览材料目录 / `list_evidence`|分页查看本报告保存材料，可按已知类型、账号或保存正文关键词筛选|不是外部搜索；目录没有出现的账号或材料不能由工具补造|
|读取原文 / `read_evidence`|按引用编号、文字偏移读取保存正文；单次最多 12000 字，并记录全文长度与文本校验值|返回的是保存文本及实际阅读窗口；长文须继续读取后面的片段，不按标题猜正文|
|核对保存账号资料 / `inspect_account`|看保存账号的类型依据、核验状态、有关材料及有引用的观察关系|类型与核验状态分开；未知保留未知，名称、自称、蓝标或关注不能决定主体与隶属|
|追查有向关系路径 / `trace_observed_path`|沿有原始观察引用的已保存关注边，按方向查最多 3 跳路径|每条边须有实际保存的公开可见列表依据；不能反向补线，关注路径不等于组织隶属、指挥或协调|
|比较调查优先级 / `prioritize_frontier`|按保存节点、待继续候选及材料覆盖等结构原因排序|只给已有线索建议；不会访问新账号，不提升账号核验，也不把结构排序当政治身份或隶属证据|
|对照材料说法 / `compare_evidence`|比较 2–8 条保存材料的实际文本、摘录及已有来源审阅|差异和矛盾只是待核对候选；不能据此自动判定外部真伪或删掉其他说法|
|逐字核对引用 / `check_citation`|检查指定引用中的摘录是否与保存原文逐字一致，并记录所在位置与校验值|只证明文字匹配；翻译、空白替换或材料之外的说法不能冒充原句|

**工具记录里的实际原文与逐字匹配，不等于所述事实已经证真。** 文本校验值用于确认这份保存文字及阅读窗口，不证明来源可靠、活动已举行或组织身份属实。账号类型依据也不能传播给其关注者、被关注者或被提及者。报告中的候选解释、调查重点、差异候选、未访问分支和证据缺口都须保留限定；工具未找到路径只说明保存范围内没有得到相应结果，不能宣称全网不存在。

### 17.4 失败后“调整分析方式并续跑”

失败、部分完成、取消或中断的 AI 报告，可在任务详情选择“调整分析方式并续跑”。先读错误及已保存的阅读进度；余额、鉴权或运行工具未就绪时先处理对应问题，等待原任务结束，再提交一个续跑任务。

该入口只允许改四个运行项：**AI 调查方式、最多 AI 决策轮数、最多工具调用数、最长运行时间**。研究问题、日期、来源、原研究绑定、材料类型与报告模式保持原任务范围；不会在这里重新采集或把旧报告换成另一范围。想改变这些条件，应创建新的报告或研究。同一恢复分支已有排队、运行中的后续任务时，不能再创建第二个续跑任务。

|已保存状态|续跑如何使用|用户需要核对什么|
|---|---|---|
|成功的正文阅读批次|原文及对应来源身份、研究目标和日期未变时复用，只处理剩余或失效部分|可先保留已读的 601 条等实际成果；正文或目标、日期变化须重新核对相应阅读|
|DSH 已完整完成，输入指纹一致|经引用校验后可以复用完成的 DSH 结果，再继续报告生成与复核|指纹绑定保存材料、研究上下文、来源审阅、模型和运行协议；不是只比较账号数量|
|DSH 输入指纹变化|重新执行该输入的工具调查，不能把旧取证结论直接当作新范围的结果|材料、上下文或模型变化都可能使已完成结果不再可复用|
|DSH 尚未完整完成|保留已完成工具记录，在新的本任务专属会话中继续；同输入已用决策和工具次数仍累计|这不是恢复旧模型会话的隐含记忆；已保存工具证据可供继续核对，未完成输出不当成功结果|
|标准 AI 报告已有成功阅读，最终生成失败|可以切换 DSH 或继续标准分析，符合条件的成功阅读复用|次数上限仅约束新增的 DSH 阶段，不能代替最后保存报告的检查|

报告的“创建重试任务”和“调整分析方式并续跑”都会先打开“免费预览报告续跑”，读取保存进度并比较输入，不在预览中调用模型。选择输入、检查影响后，才创建与原任务关联的新任务，不覆盖原来的失败终态。原任务失败不表示资料丢失，新的任务进入队列也不表示已完成。取消后等待停止，成功保存的材料、阅读与工具记录仍可供复核。

| 续跑输入 | 使用时机与影响 |
|---|---|
| 原输入续跑（默认） | 使用原任务在分析前保存并校验的完整来源、编号顺序和审核上下文。后来新增或修改的资料与核验结果不会自动带入。阅读、工具调查、初稿和压缩阶段仍分别核对指纹与证据，不能仅凭“有保存进度”保证直接跳过。 |
| 使用最新审核上下文重新生成 | 保留原任务的目标和日期，使用当前保存的资料及账号、关系审核结果。完全匹配的旧阅读片段可候选复用；上下文变化时，工具调查、综合和压缩可能需要重新执行并产生模型费用。选择后需明确确认，不会由程序自动代选。 |

预览列出来源、账号和关系主张的新增、移除、修改合计，匹配与待处理的阅读片段数量，以及后续阶段的复用条件。旧版本未保存完整输入快照时，原输入不可恢复，变更数量显示未知；已有逐条阅读记录仍可按当前正文精确匹配，不能据此声称完整调查可直接续跑。预览是无需模型调用的比较，实际执行仍会检查每个阶段，不能把候选复用量当成免付费保证。

预览后若来源或审核内容又有变化，提交会被拒绝；点击“重新免费预览”再检查。对于未绑定研究的普通报告，若原来选了“读取公开原文”，最新输入模式不会静默省略这个步骤：应新建报告完成读取后再分析；已有完整原输入快照仍可沿原输入续跑。研究报告使用其保存材料，不受这条普通报告限制。

### 17.5 工具结论的自动纠正与完整记录续用

DSH 结束结果中的格式、引用编号、原文窗口或逐字摘录未通过校验时，工作台会先拒绝保存，将固定校验反馈交回同一 DSH 会话，让模型按需补读原文、核对引用，再提交完整结果。它不能跳过校验，也不能通过删除来源限制来变成成功报告。

同一输入恢复链的工具结束结果纠正 **累计最多 2 次**，次数在继续调用模型前保存，普通续跑不会清零。纠正仍计入已有 DSH 模型与工具次数；这是防止反复无效纠正的停止门槛，不是费用预算。两次后仍不合格时保留阅读与取证记录，并显示失败，不能当作报告完成。这个门槛与下一节的全文阅读摘录纠正分别计数。

未完成 DSH 任务续跑时，会带回全部不同的工具结果；完全相同的重复记录合并后按紧凑 JSON 传入，不只保留最后 32 条。原始按时间排序的调用记录不删减，不同阅读窗口、摘录或工具结果不会合并。这样能继续使用前面已经读过的原文和已经核对的摘录；同一输入的模型与工具次数仍累计。

对于数百条材料的长任务，可将决策、工具和最长运行时间都设为 **0**，让分析按证据范围完成；希望有技术停止条件时，也可填写如 **128 轮决策 / 1024 次工具 / 360 分钟**。这些设置不能保证固定费用或成功，仍需看实际阶段与保存报告。

材料需要分层压缩时，每批摘要最多纠正 12 次，并保存被拒草稿、具体问题和累计次数。每批只按本批实际提供的帖文、简介或关注观察复核；全研究统计不能充作本批证据。最终成稿保留 DSH 已完成调查的发现与限制，并一并计算上下文容量；来源、逐字摘录或语义复核仍未通过时，不保存为完成报告。

对于能定位到具体发现的复核问题，模型只提交被点名发现的替换或拆分；其余发现及逐字引文由程序原样保留。修改整批未被点名内容、返回错误格式或漏掉必需片段会被拒绝，坏响应、目标索引及纠正次数继续保存。合并后仍复核整批原文；局部修正不是审核通过。无法定位的整体格式或覆盖问题，仍要求完整草稿修正。

### 17.6 原文摘录纠正的停止门槛

全文阅读如果仅因摘录没有逐字对应保存原文而未通过，系统可为该批再要求模型重新阅读和纠正 **最多 1 次**。纠正仍使用同样的逐字来源校验；坏修正、翻译摘录或伪造引文不会被接受为成功阅读。其他结构、未知引用或遗漏等错误，不因这个入口就被自动放行。

同一报告恢复链的摘录纠正 **累计最多 12 次**，这是防止反复失败的技术停止门槛，不是收费上限，也不属于 DSH 的 24/64 或建议 32/96 次数。累计耗尽或纠正再次失败时任务保留成功批次与明确错误，不继续无限尝试，不凭进度强行保存不合格报告。普通重试保留已使用的纠正次数；先核对保存原文、错误与模型输出质量，再选择正常续跑或重新界定独立任务。

每次完成后仍照第 16 节检查：候选与事实分开，缺口说清楚，报告终态及保存结果已核对，来源快照和备份确实可以打开。

## 18. 让 Codex、Claude Code、DSH 或其他 Agent 操作

软件内无需另开聊天窗口。你在熟悉的 Agent 对话框提出任务，Agent 使用本产品随包附带的 `peace-atlas` Skill 与本机接口操作。界面和接口共享研究、报告及清理规则，结果仍在工作台和任务中心保存。

### 18.1 一次安装，按需授权

1. 完整桌面包中找到 `resources/backend/app/workbench/agent_assets`。Mac 包从 `PEACE ATLAS.app/Contents/Resources/backend/app/workbench/agent_assets` 查找。先读 `INSTALL.md`；Skill 是其中的整个 `peace-atlas` 文件夹。
2. 复制完整 Skill 文件夹到该 Agent 宿主支持的 Skill 目录，或使用下方安装命令。安装程序只写入明确选择的新目录，拒绝覆盖已存在目录，不修改宿主全局设置，不复制连接凭据。
3. 在宿主 Skills 列表核对能看到 `peace-atlas`。尚未安装时，可以把本软件的 `INSTALL.md` 或公开 manifest 地址明确交给 Agent，让它按文档提示安装。未配置的 Agent 无法自动知道任意本机软件的安装位置。
4. PEACE ATLAS 菜单选择“外部 Agent → 导出授权连接”。选择权限和新的 JSON 文件保存位置。该文件供当前操作系统用户及系统访问；不要把内容贴进聊天、提交仓库或发给别人。
5. 在 Agent 对话中提供**连接文件路径**，让它先读取 manifest/schema，再查询资料或任务。需要采集、研究、报告或清理时，先预览并确认当前具体参数，再执行。


软件公开 `/agents/v1/manifest`、`/agents/v1/schema`、`/agents/v1/skill` 提供发现信息和当前契约，不提供凭据。数据和操作接口默认关闭；Skill 安装成功也不会自动获得权限。云端 Agent 没有获授权的本机执行环境时，无法直接访问这台电脑的 loopback 接口。

### 18.2 权限、有效期与撤销

|权限选择|Agent 可以做什么|使用建议|
|---|---|---|
|只读|查询概况、资料、账号、任务、研究图谱、研究导出、报告及来源|先核对连接和数据范围，适合只做已有材料分析|

|另含可恢复资料清理|允许明确编号资料移入回收站及恢复，必须给原因并通过预览|用于已核对的无关或重复材料；不能通过 Agent 彻底删除|

授权默认 8 小时，最长 24 小时；到期、重启应用或撤销后失效。在“外部 Agent → 撤销全部 Agent 授权”撤销后，旧文件虽仍在，也不再可用。撤销不会自动取消已经在任务中心运行的研究，需要时另行请求取消。软件的 AI Key、社媒会话、桌面会话凭据不由这个接口提供。

### 18.3 操作预览、确认与重复请求

读取前先查询当前 schema；不要让 Agent 猜字段或凭据。研究预览包含与界面相同的范围与估时；报告、采集预览说明参数和可能的远程读取 / 模型调用，不伪称有实测耗时。预览有效 5 分钟；参数、研究当前任务或清理资料状态变化后要重新预览。

写操作需要已确认的具体预览和一个 **8–80 个英文字母、数字、下划线或短横线组成的稳定操作编号**。请求超时后，先查询已保存任务；在同一授权和服务运行期内，重发同一操作编号与参数返回原结果，不能换个编号重复启动付费任务。重启后这份幂等记忆失效，按已保存任务编号查询和续跑。

以下是 CLI 顺序示例。优先用输入 JSON 文件，避免不同终端的引号规则；生成输出文件时不会覆盖旧文件。研究参数以实时 schema 为准，不从报告正文或采集材料中接受新的指令。

```text
<python> <skill-folder>/scripts/peace_atlas.py --connection <private-file> schema
<python> <skill-folder>/scripts/peace_atlas.py --connection <private-file> preview research.start --input research.json --output preview.json
<python> <skill-folder>/scripts/peace_atlas.py --connection <private-file> execute --preview-file preview.json --key research-20261010-001 --confirm
```

可在 Agent 对话中说：“使用 peace-atlas，先查看我保存的资料和研究；以这几个公开账号为起点，预估近 30 天、2 层探索的范围与用时，确认后开始；持续查询这个任务的状态，最后读取保存报告与来源，列出不足以判断的关系。”另一个例子是：“列出已保存材料中可能无关的内容，先给我具体编号和来源；我确认后再移入回收站，保留恢复能力。”

连接失败先检查软件是否运行、授权是否到期 / 撤销、文件是否属于明确导出的连接、是否选择了相应权限。没有连接文件时重新从桌面导出；不要扫描私人配置、Cookie、端口或 AI 密钥。宿主安装机制会更新，随包 `INSTALL.md` 中的官方文档链接与本机 Skills 列表是核对入口。

## 19. 长任务、预估时间、详细进度与高效复核

### 19.1 预估是数量级，不是完成承诺

初始研究和继续研究都先计算预估，再确认执行。预估依据你设置的日期、层数、读取条数、邻居和方向及预设情景，当前未按本机或该平台的实测速度校准；平台访问限制、可见数据量、去重、模型响应及纠正次数会造成偏差。界面给出的区间用于决定是否接受长任务，不保证精确结束时刻、取得数量或固定费用。

默认总量与总时长 0 更适合按范围做完；仍建议先用 1–2 层和少量明确起点检验候选质量。深度、邻居和多个方向共同决定扩张速度。一次扩大所有读取参数可能带来数小时甚至更长的采集、逐条分析与报告；先核对平台结果，再增加最有价值分支。

连续任务串必须有正数规划份额。普通采集仍是小任务入口，最多 100 条；更大主题工作使用探索或任务串。普通资料库报告当前一次来源选择最多 5000 条；日期划分和独立报告仍是该入口的范围边界。研究来源快照与普通资料选择的规则不同，按实际预览和错误说明判断。

### 19.2 看各阶段真实进度

任务详情按当前实际工作区分采集范围、账号访问、材料 / 关系保存、逐条全文阅读、DSH 决策和工具、分层压缩、报告草稿生成及最后复核。压缩会显示当前层、批次、完成单元、请求数量及已复用批次；阶段开始或进入更高层时，本阶段计数可从新的范围重新开始。

进度不是整体真实性评分。某阶段 100% 不等于报告已保存；静态总进度暂未变化时，也应查看当前批次、阅读或工具事件。只有任务达到终态、保存的报告能打开并有来源快照，才说明要求的报告流程完成。

0 时间取消了额外总时限，但单次网络请求仍有超时、实际模型上下文仍须容纳请求，无效输出仍受纠正门槛控制。取消可以在阶段间检查；当前网络请求或本地处理结束前可能仍需等待。保持软件运行及电脑唤醒；要恢复时按保存任务的后续入口继续，不反复新建。

### 19.3 减少重复审核，保留最终核对

分层摘要已通过复核且材料、阅读、研究目标、研究上下文、取证结果和相关模型设置没有变化时，可复用。只修改报告草稿或纠正说明，不再把同一原文摘要全部压缩、复核一遍。保存原文、来源身份、阅读内容、日期范围或目标改变，会使相应缓存失效；旧状态不能凭相同账号数被当作新证据。

每次新报告草稿仍进行独立的最终报告复核，检查引用、来源角色、事实与推断的区分及证据缺口。缓存命中只减少重复材料处理，不说明外部事实已证真。局部纠正只替换被点名内容，其他保存摘录原样保留；无法定位的问题仍需完整修正。

### 19.4 软件文件与研究资料分别整理

“资料库 → 清理资料”的回收站用于研究记录，按第 15 节预览、给原因、移入和恢复。安装目录中的重复旧构建、临时资源编辑文件与研究资料是不同对象。桌面构建现会在结束后清理自己的资源编辑临时目录。

本轮历史构建回收另附清单与恢复说明，回收到 Windows 回收站的目录可按原路径恢复。回收站占用同一磁盘时，项目目录变小不等于磁盘立即释放同等空闲空间；不要将“整理完成”理解为已彻底删除或清空回收站。保留的旧包、ZIP、当前应用和研究备份仍需按用途核对。

本手册参数依据 2026 年 10 月 10 日本轮页面与校验规则整理。真实平台会话、公开采集、DSH 取证及模型报告结果，以每次任务终态和保存记录为准。


## 20. 自动审核、核验与 Agent 接口


资料库、组织与账号、研究工作台以及活动地图均可打开“自动审核与核验”。使用已保存的 DeepSeek 连接，通过 DSH 工具逐批读取原文、查找独立公开出处、核对逐字摘录，保存审核决定。无需逐条点击人工审核。

## 操作顺序

1. 保存 AI 连接并确认配置就绪。应用需要完整 DSH 运行时。
2. 点击“自动审核与核验”，选择审核类别，默认覆盖账号、关系主张和活动。范围来自整个已保存资料库，不沿用当前页面筛选、地图日期或研究编号；以预估显示的各类条数为准。
3. 点击“预估范围与用时”。检查各类条数、每批数量、模型、粗略用时和网络访问选项。
4. 点击“同意预估并开始自动审核”，任务将在后台依次处理所有选中内容。
5. 在任务中心查看已保存条数、当前阶段、模型与工具次数、逐条依据和账号核验诊断。可“导出完整审核记录”。
6. 保持应用运行和电脑唤醒。取消、中断或失败时已提交的模型审核批次保留。尚未提交的材料未改变时，在原任务上重试会跳过已提交批次；若提示材料或结论已改变，重复重试仍使用旧快照，应重新打开自动审核、重新预估并创建当前范围的新任务。

## 参数

| 参数 | 用途与设置 |
|---|---|
| 账号类型与身份核验 | DS 判别组织、个人或证据不足。程序另行核对独立站点准确账号回链；类型判别本身不授予已核验状态。默认选中。 |
| 关系主张 | 审核已有关系推断或自述，记录确认、排除或证据不足。关注、共同关注、转帖和声援不能升级为组织隶属。默认选中。 |
| 活动与举办地 | 审核已有活动线索，核对实际日期、活动描述和举办地。发布日期不能补成活动日期。默认选中。 |
| 每批记录数 | 默认 16，可设 1–40。控制单次工具调查的材料量，便于稳定保存。不是任务总量限制，所有选中记录会分批处理。资料复杂时可减小，简单时可增大。 |
| 重新审核已有结论 | 默认关闭，只处理未审内容。开启后纳入已有结论及证据不足记录，重新调用模型。人工锁定账号整条不进入本流程，包括本流程的身份核验；需要补核验时，使用独立“自动核验候选账号”入口。重审不强制刷新已核验身份；核验诊断中 retained 表示保留已有已核验状态，cached 表示复用有效缓存。 |
| 允许独立公开网页 | 默认开启，允许搜索、读取独立公开 HTTPS 来源及程序回链检查。关闭仍调用 DeepSeek，只使用保存材料并跳过外部身份核验；当前独立证据要求使账号类型和关系主张无法获得新的肯定确认，充分的原文仍可支持活动确认。若同时重审，未锁定的旧肯定结论可能改为未知或证据不足。 |
| 来源读取方式 | 默认“复用有效期内已保存来源”：在新任务第一次需要某网页时，复用 1 小时内成功保存的内容；过期或校验不通过就重新读取。“强制刷新”跳过跨任务复用，新内容仍可保存供后续使用。“本次关闭”既不读也不写跨任务缓存。三种方式都可复用本任务内已读取的同一份网页，避免调查进行中混入不同版本。更改后必须重新预估。 |
| 用时预估 | 根据记录与批次数提供粗略范围，未按本机校准。网页、来源覆盖与模型工具调用影响实际耗时，可能超过范围。它不是停止时限。 |

DeepSeek 按实际模型请求计费，关闭公开网页不会关闭模型调用。每批记录数和用时预估不是收费额度；本流程没有总体费用、模型调用数或工具调用数上限，可在任务中心取消。

来源有效期控制的是新任务能否复用旧捕获，不是任务运行时限。长任务仍使用本任务已经读取的固定内容；需要现场重读时，以“强制刷新”开始一个新审核任务。关闭“允许独立公开网页”后，也不能借跨任务缓存读取外部网页。来源缓存只保存内容，不继承其他账号的身份核验结论；回收资料时会清掉相应来源的派生缓存，独立报告快照保留。

任务详情的“来源读取与复用”分别显示跨任务复用、本任务内复用、成功新读取和新读取请求次数。请求次数包含失败，所以不一定等于成功次数。“查看来源捕获记录”显示原捕获时间、有效期和读取方式，时间按日本时间展示，最多列出 32 条记录并说明省略数量。复用旧内容不表示刚刚现场访问；没有统计的旧任务显示未记录，不补算为零。缓存只能减少适合复用的网页读取，不能保证减少模型调用或缩短整项任务的固定比例。

该流程没有额外总体记录数或总时长停止。单次网页请求仍有超时，模型仍有实际上下文限制，工具参数和最终结果仍需校验。不存在关闭这些保护就能保证获取全部公开信息的设定。

## 如何解释结果

“审核已完成”表示本次指定内容都已留下审核结果。确认、排除、证据不足分别展示，不能把证据不足当作已经证实。普通个人政治身份或组织成员资格不能根据姓名、自述、关注网络推断。

类型标记、账号身份核验、关系主张和活动统计分别保存。未知账号类型可以是已审结论，并说明缺口；准确主页回链、独立站点主体说明和逐字原文依据缺失时保留未知。人工锁定账号不进入本流程；其类型不会被覆盖，身份补核验可用独立候选账号核验入口。

活动的证据不足记录不进入地图分母。地图仍按所选实际活动日期范围内已核对、已定位且去重的活动计算各地占比。网页中普通地名提及、发布日期、作者所属地和未确定举办的计划均不能代替实际活动日期与举办地。

模型提出确认活动但已核对摘录不支持完整日期、活动描述或所填举办地时，程序不采纳该确认建议，将该条记录为“证据不足”，清空拟写入的日期和举办地，并保留原始材料、已核对摘录及具体原因。其他有效条目继续保存。遗漏、重复或未知编号、无效字段以及未经逐字核对的引用仍会阻止整批写入，不能借此绕过证据校验。

开启公开网络时，每个最终未判定的账号都须经过独立出处调查。登记出处优先读取，同时提供有界的补充检索；搜索摘要不作核验依据，离题结果不会提供给模型。Bing、DuckDuckGo 或 Google 可能返回无关结果、验证码或需要 JavaScript 的页面，此时记录具体限制，保留未知；程序不会绕过平台访问限制。单账号搜索最多尝试三个提供方，单请求 25 秒、搜索总预算 85 秒，属于防止请求卡死的保护，不是整个任务的停止时限。

原有人工或官方登记的目标来源可以使用正文内该目标的准确账号主页回链；这项依据只适用于被登记的目标账号，不能授权同页其他账号，也不能使自动发现的来源获得人工登记地位。类型判别、独立身份核验继续分别展示。

关系确认还需核对原记录保留的地区、领导者、职务或刊物等身份限定。独立出处只支持其中一部分时，整条保持证据不足，不能将基本组织名的匹配扩展为全部限定已证实。组织官网指认的信息发布账号仅支持该账号发布归属的范围，不能据此确认普通个人成员身份、其他组织关系或原候选理由的全部背景叙述。

原始资料、真实观察关系和来源链接保留。审核只更新结论与记录，不删除原文、不新增猜测连线。来源更正会使旧活动结论重新进入待审队列。审核预览与写入之间材料改变时，该批全部拒绝写入，需要重读和重新预览。

## 外部 Agent

在桌面“外部 Agent → 导出授权连接”选择“审核、类型判定与账号核验”，即可单独授予 `read` 和 `review` 权限。只读或研究权限不会自动获得审核写入权限。连接文件应由用户选择，不能从正式配置或日志提取桌面令牌。

| 操作 | 作用 |
|---|---|
| `review.queue` | 读取 accounts、claims 或 activities 的待审队列。返回编号、原始材料和当前 `expected_sha256`。支持分页。 |
| `review.batch` | 外部 Agent 自行调查后批量提交有依据的决定。先 preview，再按同一预览 execute。最多 500 项一个原子提交；更大的集合继续分批，不是总量停止。 |
| `review.start` | 按与页面相同的参数预估并启动 DeepSeek/DSH 自动审核，包含独立公开回链核验。 |
| `job.get` | 查询实际进度、已提交结论和核验诊断。 |
| `job.cancel` / `job.retry` | 在 `run` 授权范围内取消或重试。仅有 review 授权时可从软件任务中心操作。 |

使用随包 Skill/CLI 的 manifest 和 schema 读取当前契约。写入操作继续遵循预览、授权确认和稳定操作键；重发同一请求应保留同一键。CLI 无需 AI Key，review.start 的实际模型请求由应用已有配置发起并按实际调用计费。review.batch 提交本身不调用应用模型；外部 Agent 前置调查的费用取决于其宿主。完整 JSON 导出包含公开原始快照、工具证据、逐条决定与回链诊断，供复查。
