## 产品完成标准

1. 核心流程：资料导入或公开新闻采集 → 持久保存及去重 → 资料详情与原始来源 → 证据报告 → 可核对的下载。
2. 数据可靠性：任务和草稿可以跨刷新、退出与重启保留；备份可以从正在运行的 SQLite 生成完整一致的快照，并在独立资料目录实际恢复。
3. 大研究结果：界面可限制展示数量，下载必须包含全部已保存材料、关系和声明，并保留人工核对的备注与证据链接。
4. 使用可靠性：错误下载能显示原因；越界分页能回到有效页；重复操作和迟到响应不会意外重开界面或重复提交。
5. 桌面可靠性：启动标记对应当前进程，设置保存失败不留下错误运行配置，正常退出等待后台保存与清理完成。
6. 可交付性：从稳定源码重新构建 Windows x64 与 Apple Silicon 包，核对源码、manifest 与包内字节，实际启动 Windows EXE 并检查关闭。
