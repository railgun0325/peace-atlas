# 自动审核、核验与 Agent 接口补充说明

资料库、组织与账号、研究工作台以及活动地图均可打开“自动审核与核验”。使用已保存的 DeepSeek 连接，通过 DSH 工具逐批读取原文、查找独立公开出处、核对逐字摘录，保存审核决定。无需逐条点击人工审核。

## 操作顺序

1. 保存 AI 连接并确认配置就绪。应用需要完整 DSH 运行时。
2. 点击“自动审核与核验”，选择审核类别，默认覆盖账号、关系主张和活动。范围来自整个已保存资料库，不沿用当前页面筛选、地图日期或研究编号；以预估显示的各类条数为准。
3. 点击“预估范围与用时”。检查各类条数、每批数量、模型、粗略用时和网络访问选项。
4. 点击“同意预估并开始自动审核”，任务将在后台依次处理所有选中内容。
5. 在任务中心查看已保存条数、当前阶段、模型与工具次数、逐条依据和账号核验诊断。可“导出完整审核记录”。
6. 保持应用运行和电脑唤醒。取消、中断或失败时已提交的模型审核批次保留。尚未提交的材料未改变时，在原任务上重试会跳过已提交批次；若提示材料或结论已改变，重复重试仍使用旧快照，应重新打开自动审核、重新预估并创建当前范围的新任务。

## 参数

| 参数 | 用途与设置 |
|---|---|
| 账号类型与身份核验 | DS 判别组织、个人或证据不足。程序另行核对独立站点准确账号回链；类型判别本身不授予已核验状态。默认选中。 |
| 关系主张 | 审核已有关系推断或自述，记录确认、排除或证据不足。关注、共同关注、转帖和声援不能升级为组织隶属。默认选中。 |
| 活动与举办地 | 审核已有活动线索，核对实际日期、活动描述和举办地。发布日期不能补成活动日期。默认选中。 |
| 每批记录数 | 默认 16，可设 1–40。控制单次工具调查的材料量，便于稳定保存。不是任务总量限制，所有选中记录会分批处理。资料复杂时可减小，简单时可增大。 |
| 重新审核已有结论 | 默认关闭，只处理未审内容。开启后纳入已有结论及证据不足记录，重新调用模型。人工锁定账号整条不进入本流程，包括本流程的身份核验；需要补核验时，使用独立“自动核验候选账号”入口。重审不强制刷新已核验身份；核验诊断中 retained 表示保留已有已核验状态，cached 表示复用有效缓存。 |
| 允许独立公开网页 | 默认开启，允许搜索、读取独立公开 HTTPS 来源及程序回链检查。关闭仍调用 DeepSeek，只使用保存材料并跳过外部身份核验；当前独立证据要求使账号类型和关系主张无法获得新的肯定确认，充分的原文仍可支持活动确认。若同时重审，未锁定的旧肯定结论可能改为未知或证据不足。 |
| 用时预估 | 根据记录与批次数提供粗略范围，未按本机校准。网页、来源覆盖与模型工具调用影响实际耗时，可能超过范围。它不是停止时限。 |

DeepSeek 按实际模型请求计费，关闭公开网页不会关闭模型调用。每批记录数和用时预估不是收费额度；本流程没有总体费用、模型调用数或工具调用数上限，可在任务中心取消。

该流程没有额外总体记录数或总时长停止。单次网页请求仍有超时，模型仍有实际上下文限制，工具参数和最终结果仍需校验。不存在关闭这些保护就能保证获取全部公开信息的设定。

## 如何解释结果

“审核已完成”表示本次指定内容都已留下审核结果。确认、排除、证据不足分别展示，不能把证据不足当作已经证实。普通个人政治身份或组织成员资格不能根据姓名、自述、关注网络推断。

类型标记、账号身份核验、关系主张和活动统计分别保存。未知账号类型可以是已审结论，并说明缺口；准确主页回链、独立站点主体说明和逐字原文依据缺失时保留未知。人工锁定账号不进入本流程；其类型不会被覆盖，身份补核验可用独立候选账号核验入口。

活动的证据不足记录不进入地图分母。地图仍按所选实际活动日期范围内已核对、已定位且去重的活动计算各地占比。网页中普通地名提及、发布日期、作者所属地和未确定举办的计划均不能代替实际活动日期与举办地。

模型提出确认活动但已核对摘录不支持完整日期、活动描述或所填举办地时，程序不采纳该确认建议，将该条记录为“证据不足”，清空拟写入的日期和举办地，并保留原始材料、已核对摘录及具体原因。其他有效条目继续保存。遗漏、重复或未知编号、无效字段以及未经逐字核对的引用仍会阻止整批写入，不能借此绕过证据校验。

开启公开网络时，每个最终未判定的账号都须经过独立出处调查。登记出处优先读取，同时提供有界的补充检索；搜索摘要不作核验依据，离题结果不会提供给模型。Bing、DuckDuckGo 或 Google 可能返回无关结果、验证码或需要 JavaScript 的页面，此时记录具体限制，保留未知；程序不会绕过平台访问限制。单账号搜索最多尝试三个提供方，单请求 25 秒、搜索总预算 85 秒，属于防止请求卡死的保护，不是整个任务的停止时限。

原有人工或官方登记的目标来源可以使用正文内该目标的准确账号主页回链；这项依据只适用于被登记的目标账号，不能授权同页其他账号，也不能使自动发现的来源获得人工登记地位。类型判别、独立身份核验继续分别展示。

关系确认还需核对原记录保留的地区、领导者、职务或刊物等身份限定。独立出处只支持其中一部分时，整条保持证据不足，不能将基本组织名的匹配扩展为全部限定已证实。组织官网指认的信息发布账号仅支持该账号发布归属的范围，不能据此确认普通个人成员身份、其他组织关系或原候选理由的全部背景叙述。

原始资料、真实观察关系和来源链接保留。审核只更新结论与记录，不删除原文、不新增猜测连线。来源更正会使旧活动结论重新进入待审队列。审核预览与写入之间材料改变时，该批全部拒绝写入，需要重读和重新预览。

## 外部 Agent

在桌面“外部 Agent → 导出授权连接”选择“审核、类型判定与账号核验”，即可单独授予 `read` 和 `review` 权限。只读或研究权限不会自动获得审核写入权限。连接文件应由用户选择，不能从正式配置或日志提取桌面令牌。

| 操作 | 作用 |
|---|---|
| `review.queue` | 读取 accounts、claims 或 activities 的待审队列。返回编号、原始材料和当前 `expected_sha256`。支持分页。 |
| `review.batch` | 外部 Agent 自行调查后批量提交有依据的决定。先 preview，再按同一预览 execute。最多 500 项一个原子提交；更大的集合继续分批，不是总量停止。 |
| `review.start` | 按与页面相同的参数预估并启动 DeepSeek/DSH 自动审核，包含独立公开回链核验。 |
| `job.get` | 查询实际进度、已提交结论和核验诊断。 |
| `job.cancel` / `job.retry` | 取消或重试自动审核任务需 `review` 授权；其他研究、采集和报告任务需 `run` 授权。预览与执行都会核对任务类别，只有其中一类授权不能操作另一类任务。 |

使用随包 Skill/CLI 的 manifest 和 schema 读取当前契约。写入操作继续遵循预览、授权确认和稳定操作键；重发同一请求应保留同一键。CLI 无需 AI Key，review.start 的实际模型请求由应用已有配置发起并按实际调用计费。review.batch 提交本身不调用应用模型；外部 Agent 前置调查的费用取决于其宿主。完整 JSON 导出包含公开原始快照、工具证据、逐条决定与回链诊断，供复查。
